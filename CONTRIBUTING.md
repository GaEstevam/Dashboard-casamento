# Como contribuir

Obrigado por considerar uma contribuição para o Nosso Sim.

## Fluxo recomendado

1. Crie um fork do repositório.
2. Abra uma branch curta e descritiva, como `feat/filtro-por-mesa`.
3. Instale as dependências com `npm ci`.
4. Faça alterações pequenas e focadas.
5. Execute `npm run check`.
6. Abra um pull request descrevendo o problema e a solução.

## Padrões

- Use TypeScript e mantenha a verificação estrita ativa.
- Preserve o processamento local e não envie dados pessoais a serviços externos.
- Não inclua planilhas, backups ou dados reais nos commits.
- Mantenha textos visíveis em português do Brasil.
- Teste desktop e celular quando alterar o layout.
- Atualize a documentação quando mudar o formato esperado da planilha.

## Issues

Ao relatar um problema, informe:

- comportamento esperado e observado;
- navegador e sistema operacional;
- passos mínimos para reproduzir;
- nomes das abas/colunas envolvidas, sem incluir dados pessoais.
