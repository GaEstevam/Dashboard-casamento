# Segurança e privacidade

## Dados locais

O Nosso Sim processa planilhas no navegador e armazena os dados no `localStorage`. Não existe backend ou sincronização automática.

A proteção por senha é local e serve para evitar acesso casual no mesmo navegador. Ela não substitui criptografia de disco, contas separadas ou controles do sistema operacional.

## Recomendações para publicação

- Nunca versione planilhas reais, arquivos de backup ou listas de convidados.
- Revise o histórico do Git antes de tornar um repositório público.
- Hospede somente o conteúdo compilado a partir deste código.
- Importe apenas arquivos próprios e confiáveis.
- Use HTTPS ao publicar a aplicação.

## Relato de vulnerabilidades

Não publique detalhes sensíveis em uma issue pública. Use o recurso de relato privado de vulnerabilidades do GitHub quando ele estiver habilitado no repositório.
